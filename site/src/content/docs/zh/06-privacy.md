## 不联网

`build` 完全离线。`record` 只连你用 `--upstream` 指定的地址，转发 Agent 本来就要发的请求。没有账号、统计或遥测。

## 存什么

`record` 只保存每次请求的方法、路径、时间和正文。**请求头不写盘**，所以 API key、cookie、组织 ID 这类放在请求头里的内容不会进文件。响应不保存。

`--rule` 会把规则文件复制进运行目录，并在 `fixtures.json` 里记下原来的绝对路径。

## 生成的页面里有什么

`build` 生成的 HTML 包含请求原文：系统提示、对话、工具结果，以及其中可能出现的文件内容和路径。把它当作和运行记录同样敏感的东西：只在本机打开；要分享，先对运行目录脱敏，再生成。
