## 层

请求里的每一段文字都归到一个层：

| 层 | 是什么 |
| --- | --- |
| 系统 | 系统提示、`instructions`、`developer` 消息，以及 role 为 system 的消息 |
| 用户 | 用户消息，包括 Agent 自己插进用户消息里的提示 |
| 助手 | 模型之前的回复 |
| 工具调用 | 模型发起的工具调用 |
| 工具结果 | 工具返回的内容 |
| 工具定义 | 请求里附带的工具列表 |

颜色只用来区分层，每个格子上都写着层的名字。

## 总览

一行一个运行，一列一条规则。格子是规则**第一次出现**的那一层；空心框表示在所有 Agent 请求里都没有出现。右边是请求数和严重标记数（从未送达、消失）。点一行进入回放。

## 规则追踪

每行一个规则文件，每列一次请求。看一条规则从哪一步开始出现、在哪一步消失、后来有没有回来。带斜纹的格子是只送了一部分；`×2` 表示同一条规则在这次请求里出现了两处。淡色的列是旁支请求。

## 模型收到了什么

每次请求画成一条长条，长度按字符数等比例。条里按层分色，细竖线是规则文字的位置。悬停可以看到每一层的字数和占比。

## 逐段查看

选中的那次请求拆成一段一段，按请求里的顺序排列。左边是层，中间是这段在请求 JSON 里的位置（例如 `messages[3].content[0]`），右边是字数。「新增」表示上一次 Agent 请求里没有这段文字。点开就是原文，规则行高亮。

## 链接

地址栏会跟着变成 `lens.html#run=<名字>&step=<n>`，复制下来就能直接打开到同一个运行的同一步。`?lang=zh|en` 切换语言，`?theme=light|dark` 切换浅色或深色。
